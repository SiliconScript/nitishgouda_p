01. The Bottleneck

The "Float Bloat"

Modern AI is constrained by the Memory Wall. Standard networks store weights as 32-bit floating-point numbers (FP32). Computing the math takes 1 unit of energy, but fetching those heavy 32-bit packets from memory takes 100 units of energy.

Moving billions of multi-color FP32 values across the silicon die creates massive latency and thermal output, making standard AI impossible on microcontrollers.

02. The Solution

Information Collapse

The Sign Function maps any continuous number to exactly +1 or -1. We discard the infinite magnitude and retain only the mathematical direction. In hardware, this is stored as a single literal bit: 1 for positive, 0 for negative.

03. Silicon Speed

XNOR & Popcount

With binary weights, floating-point multipliers are physically bypassed. In the {-1, +1} domain, multiplication perfectly maps to the boolean XNOR logic gate.

Hardware executes XNOR bitwise, meaning 64 calculations happen simultaneously within a single 64-bit CPU register. The results are summed using a hardware POPCOUNT instruction.

05. Training Hack

Straight-Through Estimator

Backpropagation requires smooth, differentiable functions to adjust weights. The sign function is a harsh geometric step, meaning its gradient is zero everywhere. The network cannot learn.

The Straight-Through Estimator (STE) solves this by "lying" to the network. During the backward pass, it overrides the zero gradient, substituting a proxy gradient of 1 (when |x| ≤ 1). This allows learning data to flow backward through the non-differentiable barrier.

STEP 1

Forward Pass

Apply the real sign function. Weights are hard-binarized to exactly +1 or −1.

STEP 2

The Block

The true mathematical gradient is 0. Standard learning halts entirely.

STEP 3

Backward Pass

Substitute the gradient with 1. Gradients pass straight through the layer.

module sync_2ff(
  input wire clk, rst_n,
  input wire async_in,
  output reg sync_out
);
  reg ff1;
  always @(posedge clk or negedge rst_n)
    if (!rst_n) {ff1,sync_out} <= 2'b0;
    else {sync_out,ff1} <= {ff1,async_in};
endmodule
